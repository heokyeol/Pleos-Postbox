# Pleos Postbox (플레오스 우체통)

## 앱 이름 및 한 줄 소개

**Pleos Postbox (플레오스 우체통)**: 가족이 휴대폰으로 그려 보낸 손편지가 시동 걸 때 Pleos Postbox로 배달되어, 사랑스러운 편지로 하루를 시작하도록 돕는 차 안의 우체통입니다.

## 실행 방법
**차량용 앱**
1. 에뮬레이터(Pleos Connect v2.1.0)를 켜고 APK를 설치합니다.
   ```bash
   adb install -r apk/소풍나온수송대대_PleosPostbox_release.apk
   ```
2. 런처에서 **Pleos Postbox**를 엽니다. 알림 권한 요청이 나오면 [허용]을 누릅니다.
3. 가족 연결(QR) 화면에서 [확인]을 누르면 "새로운 편지가 2통 왔어요"가 뜹니다.
4. [읽기]를 누르면 편지가 그려지고, [답장]으로 문장 또는 음성 답장을 보낼 수 있습니다. [나중에 읽기]를 누르면 받은 편지 목록으로 갑니다.
5. **시연 패널**: 화면 오른쪽 위 모서리를 길게 누르면 열립니다. 시동 다시 켜기, 시동 알림 보내기, 주행/주차 전환, 읽음 초기화를 할 수 있습니다.

**가족용 웹**(이는 테스트를 위한 웹으로, 보낸 편지가 차량용 앱에 실제로 전송되지는 않으며 차량용 앱은 현재 더미 데이터로 작동합니다.)

1. 저장소 폴더에서 ```python3 tools/dev_server.py```를 실행합니다. 

2. http://localhost:8090 으로 접속합니다.

## 테스트 환경 및 필요한 설정

- 차량 전용 앱이므로 AAOS 에뮬레이터나 차량에만 설치됩니다.
- 서버/계정/네트워크 등 별도 설정 없이 바로 테스트 가능합니다.
- 앱에 들어 있는 더미 편지 10통으로 동작합니다.
- 주행 중 잠금은 차량의 UX 제한 신호를 따릅니다. 에뮬레이터에서는 시연 패널의 [주행 중으로]/[주차로]로 확인할 수 있습니다.
- 가족용 웹은 이해를 돕기 위한 웹 환경으로, Pleos Postbox 구동에 필수적이지 않습니다.
