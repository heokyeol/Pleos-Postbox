# Pleos Postbox (플레오스 우체통)
가족이 휴대폰으로 보낸 편지를 하루의 시작과 끝에 Pleos Connect에서 보여주는, 차 안의 그림편지 우체통 앱

**기능** 
- 시동 걸 때 "새로운 편지가 n통 왔어요" 알림이 옵니다.
- 편지를 작성한 획을 따라 생생하게 편지가 다시 그려집니다.
- 문장/음성 답장 · 주행 중 잠금(주차 때만 표시) · QR 가족 연결 등의 부가 기능이 있습니다.

**사용법**
1. 설치: `adb install --user 10 apk/허결_PleosPostbox_release.apk` (AAOS 에뮬레이터, 운전자 사용자)
2. 앱을 열고 가족 연결 화면에서 [확인] → 새 편지 도착 화면에서 [읽기]로 편지를 보고 [답장]
3. 화면 오른쪽 위를 길게 누르면 시연 패널(시동 다시 켜기, 시동 알림, 주행/주차 전환, 읽음 초기화)이 열립니다.
